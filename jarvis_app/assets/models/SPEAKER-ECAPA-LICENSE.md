# Speaker ECAPA model license

Model: mlboydaisuke/ECAPA-TDNN-Speaker-ExecuTorch

The model is an ExecuTorch export derived from SpeechBrain's
speechbrain/spkrec-ecapa-voxceleb speaker embedding model.

License: Apache License 2.0

Source model:
https://huggingface.co/speechbrain/spkrec-ecapa-voxceleb

ExecuTorch packaging:
https://huggingface.co/mlboydaisuke/ECAPA-TDNN-Speaker-ExecuTorch

The JARVIS app uses the model locally to create speaker embeddings for
opt-in voice profiles. Raw enrollment recordings are not retained by JARVIS.
