# Project JARVIS Android

Native Android JARVIS assistant project for Jerome.

This repository is configured to build the current in-house JARVIS Android source with GitHub Actions. The application uses Kotlin, Jetpack Compose, Android SDK 35, Java 17, Gradle 8.9, and package `com.jarvis.mobile`.

Current source snapshot: `ProjectJarvis-InHouse-CI-Android.zip`, stored in this repository as a Base64 payload for deterministic CI reconstruction.

Security: no OpenAI API key is committed to this repository. SIP/AI receptionist support remains disabled in the active mobile build. Automatic phone answering remains opt-in and off by default.
